# 專案管理儀表板

多專案進度追蹤 Dashboard —— 單一 HTML 檔案，開箱即用。

## 功能

- 多專案同時追蹤，卡片式切換
- 五大部門進度：產品、設計、前端、後端、QA
- User Story 清單與里程碑
- QA 測試案例表格（Pass / Fail / Pending）
- Commit 記錄時間軸（含檔案變更統計）
- 每日進度數據，支援日期切換與差異比較
- 「更新數據」按鈕，可從 data.json 拉取最新資料
- 深色 / 淺色模式自動切換
- 響應式設計，手機也能用

## 快速開始

打開 `index.html` 即可使用（內建範例資料）。

如需部署為線上版本，請參考 [DEPLOYMENT-GUIDE.md](./DEPLOYMENT-GUIDE.md)。
